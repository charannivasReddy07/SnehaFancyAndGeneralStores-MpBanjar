# Sneha Fancy & General Stores

## Status

Approved scope based on the user's request to match the supplied reference and host the site with GitHub.

## Goal

Recreate the public-facing Sneha Fancy & General Stores website as a responsive static site deployable to GitHub Pages. The reference is https://sneha-fancy-morampallibanjar.lovable.app/.

## Application

- React and TypeScript, built as a static single-page website.
- No backend, database, authentication, admin interface, product checkout, or payment processing.
- Use local static assets where available; include the reference's logo, hero, gallery, LIC logo, and Google review QR assets if accessible.
- Mobile-first responsive layout, accessible landmarks and controls, reduced-motion support, and descriptive image text.

## User experience and content

- Sticky navigation to Gallery, Products, Services, About, and Contact; a prominent Call Now action.
- Hero with the store name, local introduction, WhatsApp enquiry, and product-section link.
- Animated or static category ribbon for Footwear, Stationery, Gift Articles, Luggage Bags, Plastic Items, Bangles, Jewellery, Cosmetics, LIC Insurance, and Fino Banking.
- Four-image gallery for Bangles Collection, Bridal Jewellery, Cosmetics, and Inside the Store.
- Product categories and service cards matching the reference, including LIC insurance, personal service, and Fino Payments Bank services.
- Store story and trust statistics.
- Address, Google Maps link, telephone, WhatsApp enquiry, and Google review QR section.
- Footer and persistent WhatsApp contact action.
- Preserve the reference business details: phone 9492958698 and address in Morampalli Banjar, Bhadrachalam, Telangana 507114.

## Hosting and delivery

- Configure a GitHub Actions workflow to build and publish the static site to GitHub Pages on pushes to the repository's main branch.
- Configure the build for GitHub Pages project paths and document repository Pages setup and local development in the README.
- Verify with the project's available build and type checks.

## Out of scope

- Online payments, cart/order management, customer accounts, persisted data, and store-admin tools.
